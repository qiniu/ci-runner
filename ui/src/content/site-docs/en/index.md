# Qiniu CI Runner guides

Choose the path that matches what you want to do, then follow one guide from start to a verified result.

## Use the hosted service

Sign in to the hosted Qiniu CI Runner, connect a GitHub repository, confirm Sandbox readiness, and run your first managed job.

[Start with the hosted service](/docs/getting-started/hosted)

## Deploy runnerd

Operate your own runnerd control plane while workflow jobs continue to execute in Qiniu Sandbox.

[Deploy runnerd](/docs/getting-started/deploy)

## Build the first workflow

Copy a complete workflow using the current managed labels and learn what a successful run looks like.

[Run your first workflow](/docs/guides/workflow)

## Configure cache

Save Cache S3 in Preferences, then use `qiniu/actions-cache@v5` in the workflow.

[Configure and use Cache S3](/docs/guides/cache)

## Build a custom runner template

Add your own toolchain to a private Sandbox template, connect it to a custom Runner Spec, and verify the complete workflow path.

[Build and use a custom runner template](/docs/guides/custom-templates)

## Diagnose a problem

Start from the symptom you see in GitHub or Qiniu CI Runner and follow the checks in order.

[Open troubleshooting](/docs/troubleshooting)
