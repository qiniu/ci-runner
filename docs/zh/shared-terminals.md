# 共享 Web Terminal 会话

终端会话的归属和清理状态保存在 `terminal_sessions` 表中，实际 shell 和输出重放由 Sandbox 内的 envd 管理。runnerd 仅持有当前请求的网络连接，不再保存终端会话表、输出回放缓存、所属节点地址或会话定时器。

## 状态边界

数据库记录打开终端的账号、Job 执行批次或 Deploy revision/attempt、Sandbox ID、PTY PID、实例标识、首次输出游标、加密后的服务凭据快照、空闲期限和清理状态。用户输入和终端输出不写入数据库。

envd 为每个 PTY 保留最近 64 KiB 输出，并在进程退出后保留尾部和退出结果 30 秒。重连必须提供同一个 PTY 实例标识和字节游标；输出已被淘汰、实例已消失或 PID 被重用时明确失败，不会悄悄切换到其他 shell。输入请求出现传输错误时结果可能未知，不自动重发。

创建 PTY 前先保存 `opening` 记录和唯一标签。创建节点退出后，其他节点可使用标签核对未知结果；仅凭“暂时查不到标签”不会丢弃清理责任。关闭意图先写入数据库，再领取 20 秒清理租约并执行最长 10 秒的清理请求。失败记录保留并允许后续节点重试，已关闭记录清除复制的凭据。当前不自动删除终端历史记录。

活跃订阅每 5 秒重新检查仓库权限、执行批次并续期数据库中的 30 秒空闲期限。正常断连后重新给予 30 秒宽限；节点被强制终止时，最后一次心跳仍留下至少 25 秒，覆盖浏览器的 20 秒重试窗口。清理扫描另有最多 5 秒调度间隔。多个订阅不会缩短彼此的期限，过期判断使用数据库时钟。

终端访问通过 SDK 的只读 `Attach` 获取当前 Sandbox 地址及凭据，不恢复暂停实例，也不延长 Sandbox 的生命周期。

## 合并和生产发布顺序

1. 先审核 envd 重放实现及 API specs 协议源，发布 envd。通过 Sandbox 模板构建和区域推广流程替换实际 envd 二进制；仅升级后端 Go module 不会更新现有 Sandbox 内的 envd。
2. 合并并发布对应 Go SDK。runnerd Draft PR 的远端 feature commit 替换仅用于可复现的 CI；合并 runnerd 前必须改为正式 SDK 版本。
3. 在各个实际使用的区域、模板上创建新 Sandbox，确认 `pty_replay_supported` 能力。旧 Sandbox 可能仍携带旧 envd，会收到明确的终端升级提示。
4. runnerd 先单节点发布，验收 Jobs、Deploy 终端、撤权、重连和资源回收。表结构升级为新增表，Job/Deploy 历史不变；旧版内存中的终端不能迁移，升级后用户重新打开终端，底层任务继续运行。
5. 再扩容。节点共享数据库、会话签名密钥和加密密钥，能访问 Sandbox API 即可。`server.terminal_peer_origin` 已停用，旧 YAML 中残留的值会被忽略；不再需要节点间终端转发、每节点 HTTPS 域名或粘性会话。

新旧终端处理器的会话模型不同，切换时先排空终端连接，不将两个版本混在同一负载均衡池中。回退保留新增表；回退前由新版本完成其 PTY 清理，因为旧版本不识别这些记录。代码或本地测试通过不代表生产 Sandbox 已升级 envd。

## 验证证据边界

- envd 测试包含真实 PTY、创建 RPC 到期后继续运行、有界回放、实例标识和退出结果保留。
- SDK 测试覆盖旧 envd 拒绝、真实拦截器路径上的 5 秒心跳，以及不改变 Sandbox 生命周期的只读连接。
- PostgreSQL/MySQL 验证会话状态、条件更新、清理租约和时间兼容性；使用名称以 `_test` 结尾的独立数据库。
- PostgreSQL 三进程测试强制结束创建节点，另两个进程继续读取、输入和清理；其 Sandbox 使用独立的提供方测试服务。
- Chromium 5/15/25 秒断网测试使用真实本地 PTY。它与生产 envd 模板验收是不同的证据，不能相互替代。
